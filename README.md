PRAMOJA KATTAMUDI - PORTFOLIO WEBSITE

Files:
- index.html: website content
- style.css: custom styling
- assets/profile-photo.jpeg: supplied profile photo
- assets/Pramoja-Kattamudi-Resume.pdf: supplied resume

Preview:
Open index.html in a browser. An internet connection is needed for Bootstrap and Google Fonts CDN resources.

Publish with GitHub Pages:
1. Create a public GitHub repository named pramoja-portfolio.
2. Upload index.html, style.css, and the assets folder (keep this structure).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. After publishing, GitHub will show a website URL similar to:
   https://KattamudiPramoja.github.io/pramoja-portfolio/

Add that published URL to the resume only after confirming the website is live.
